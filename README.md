Smart Campus Placement System Using Machine Learning.

Project Overview:
Smart Campus Placement System is a web based application designed in python using Django framework. This system makes the Campus Placement Process easy and efficient by providing the facility to interact between students, placement officer and company representative..

Goal:
--> Make placement at the university easier.
--> Allows students to apply for positions.
--> Helps placement officers keep track of students and placements.
--> Allows companies to advertise vacancies and review applicants.
--> Enables candidates to be screened and interviews to be scheduled.
  
  
Technologies Used:
- Programming Language: Python
- Web Framework: Django
- Frontend: HTML, CSS, JavaScript
- Database: SQLite


Main Features:

>>Students:
-Student can be registered and logged in.
-Create a profile and upload Resume.
-View available job opportunities.
-Apply for suitable jobs.
-View interview information.

>>Placement Officer:
-Student information can be managed.
-Company and job information can be managed.
-Track placements.
-View statistics of placements.

>>Company:
-Post available job vacancies.
-Review student applications.
-View application information.
